# 📄 포트폴리오 (Vanilla JS Edition)

빌드 도구 없는 순수 자바스크립트와 최신 브라우저 기능을 활용하여 구축한 개인 포트폴리오 사이트입니다.

## 🛠 주요 변경 사항: From Parcel to Vanilla

기존의 **Parcel** 번들링 환경에서 **Vanilla JS & Native ESM** 환경으로 전환하였습니다.

* **Zero Dependency:** 외부 빌드 도구(npm, Parcel) 의존성을 제거하여 브라우저에서 직접 실행 가능합니다.
* **ES Modules (ESM):** `type="module"`을 제거 하였습니다.
* **Performance:** 빌드 과정이 없어 수정 사항이 즉시 반영되며, 불필요한 번들링 오버헤드를 줄였습니다.

## 🚀 Tech Stack

* **Language:** JavaScript (ES6+), HTML5, CSS3
* **Library:** [amCharts 4](https://www.amcharts.com/) (Timeline & Data Visualization)
* **Methodology:** Responsive Web Design, Flexbox/Grid
